# Demo Script

## Flow 1: Authentication

1. Open `index.html`.
2. Register new user.
3. Login and show redirect to dashboard.

## Flow 2: Closet CRUD + upload

1. Add manual item.
2. Edit item.
3. Delete item.
4. Upload image and show success/fallback behavior.

## Flow 3: OOTD

1. Search city.
2. Fetch weather.
3. Generate recommendation.
4. Show returned outfit and auto-created history id.

## Flow 4: History

1. Open history list.
2. Edit rating/feedback.
3. Delete entry.

## Flow 5: Settings

1. Load current profile/config.
2. Update integration config fields.
3. Logout and redirect to login page.
